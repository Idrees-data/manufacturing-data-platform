# Manufacturing Data Platform

## Overview

A data engineering portfolio project built around manufacturing operations data. The project explores production performance, machine maintenance, product information, and quality inspections using Python, Pandas, SQL, and PySpark.

## Datasets

The project currently includes five datasets:

- `production.csv` — production records, machines, products, shifts, and operating hours.
- `products.csv` — product categories, costs, selling prices, and production times.
- `Machines.csv` — machine details, factories, production lines, and status.
- `Maintenance.csv` — maintenance types, downtime, and maintenance costs.
- `Quality_Inspections.csv` — inspected units, defective units, and defect types.

## Work Completed

- Loaded and explored five CSV datasets using Pandas.
- Practised analytical aggregations, filtering, sorting, and joins.
- Implemented equivalent SQL queries for analytical questions.
- Checked missing values and duplicate rows.
- Validated primary-key uniqueness and foreign-key relationships.
